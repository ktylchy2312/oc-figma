# EmptyTitle

Сгенерировано из набора компонентов Figma `EmptyTitle`.

- Разметка: [`empty-title.html`](empty-title.html) — все варианты по порядку, каждый с комментарием.
- Стили: [`empty-title.css`](empty-title.css) — требуют `foundations/tokens.css` и `code/base.css`.
- Корень: `<div>`, базовый класс `.oc-empty-title`
- Группа Feedback, уровень atom, вариантов 1

## Свойства

| Свойство | Значения | По умолчанию |
|---|---|---|
| `Label` (text) | свободный текст | `"Brak pojazdów na tym etapie"` |

## Классы

Имена заморожены в [`../_names.json`](../_names.json): пути частей принадлежат дереву Figma, и
без карты вставленный соседний слой переименовал бы класс у части, которую никто не трогал.

| Класс | Слой Figma |
|---|---|
| `.oc-empty-title` | `EmptyTitle` |
| `.oc-empty-title__label` | `Brak pojazdów na tym etapie` |

## Где используется

- Входит в состав других компонентов (1 шт. по графу Figma).
