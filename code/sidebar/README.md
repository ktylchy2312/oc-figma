# Sidebar

Сгенерировано из набора компонентов Figma `Sidebar`.

- Разметка: [`sidebar.html`](sidebar.html) — все варианты по порядку, каждый с комментарием.
- Стили: [`sidebar.css`](sidebar.css) — требуют `foundations/tokens.css` и `code/base.css`.
- Корень: `<div>`, базовый класс `.oc-sidebar`
- Группа Navigation, уровень organism, вариантов 2

## Свойства

| Свойство | Значения | По умолчанию |
|---|---|---|
| `Collapsed` (variant) | `True`, `False` | `"False"` |
