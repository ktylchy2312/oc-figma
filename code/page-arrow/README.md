# PageArrow

Сгенерировано из набора компонентов Figma `PageArrow`.

- Разметка: [`page-arrow.html`](page-arrow.html) — все варианты по порядку, каждый с комментарием.
- Стили: [`page-arrow.css`](page-arrow.css) — требуют `foundations/tokens.css` и `code/base.css`.
- Корень: `<div>`, базовый класс `.oc-page-arrow`
- Группа Navigation, уровень molecule, вариантов 8

## Свойства

| Свойство | Значения | По умолчанию |
|---|---|---|
| `Direction` (variant) | `Prev`, `Next` | `"Prev"` |
| `State` (variant) | `Default`, `Hover`, `Pressed`, `Disabled` | `"Default"` |

## Состояния

Каждое значение `State` выходит дважды: статическим модификатором (`.oc-page-arrow--state-hover`),
чтобы витрина показала все состояния разом, и псевдоклассом (`:hover`, `:active`, `:focus-visible`,
`:disabled`), чтобы компонент работал на живой странице. Наведение и нажатие гасятся на
выключенном элементе.

## Классы

Имена заморожены в [`../_names.json`](../_names.json): пути частей принадлежат дереву Figma, и
без карты вставленный соседний слой переименовал бы класс у части, которую никто не трогал.

| Класс | Слой Figma |
|---|---|
| `.oc-page-arrow` | `PageArrow` |
| `.oc-page-arrow__icon-chevron-left` | `‹` |
| `.oc-page-arrow__icon-chevron-right` | `icon-chevron-right` |

## Непривязанные значения

5 шт. Значение уехало в CSS литералом и помечено маркером TODO. Это дыра в
библиотеке Figma, а не в коде: пока переменной нет, подставлять «похожую» нельзя.

| Свойство | Значение | Почему |
|---|---|---|
| `width` | `32px` | нет шкалы размеров: ширина задана числом |
| `height` | `32px` | нет шкалы размеров: высота задана числом |
| `borderWidth` | `1px` | нет токена под толщину обводки |
| `icon-chevron-left.iconStrokeWidth` | `1` | нет токена под толщину линии иконки |
| `icon-chevron-right.iconStrokeWidth` | `1` | нет токена под толщину линии иконки |

## Где используется

- Входит в состав других компонентов (1 шт. по графу Figma).
