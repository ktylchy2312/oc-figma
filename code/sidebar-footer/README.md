# SidebarFooter

Сгенерировано из набора компонентов Figma `SidebarFooter`.

- Разметка: [`sidebar-footer.html`](sidebar-footer.html) — все варианты по порядку, каждый с комментарием.
- Стили: [`sidebar-footer.css`](sidebar-footer.css) — требуют `foundations/tokens.css` и `code/base.css`.
- Корень: `<div>`, базовый класс `.oc-sidebar-footer`
- Группа Navigation, уровень molecule, вариантов 1

## Классы

Имена заморожены в [`../_names.json`](../_names.json): пути частей принадлежат дереву Figma, и
без карты вставленный соседний слой переименовал бы класс у части, которую никто не трогал.

| Класс | Слой Figma |
|---|---|
| `.oc-sidebar-footer` | `SidebarFooter` |
| `.oc-sidebar-footer__divider` | `Divider` |
| `.oc-sidebar-footer__frame-166` | `Frame 166` |
| `.oc-sidebar-footer__oc-kontrol` | `OC-KONTROL` |
| `.oc-sidebar-footer__frame-165` | `Frame 165` |
| `.oc-sidebar-footer__wersja-1-4-2-build-2026-08` | `Wersja 1.4.2 · build 2026.08` |
| `.oc-sidebar-footer__2026-oc-kontrol` | `© 2026 OC-KONTROL` |
