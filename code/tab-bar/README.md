# TabBar

Сгенерировано из набора компонентов Figma `TabBar`.

- Разметка: [`tab-bar.html`](tab-bar.html) — все варианты по порядку, каждый с комментарием.
- Стили: [`tab-bar.css`](tab-bar.css) — требуют `foundations/tokens.css` и `code/base.css`.
- Корень: `<div>`, базовый класс `.oc-tab-bar`
- Группа Navigation, уровень organism, вариантов 1

## Свойства

| Свойство | Значения | По умолчанию |
|---|---|---|
| `Show Tab 3` (boolean) | `true`, `false` | `true` |
| `Show Tab 4` (boolean) | `true`, `false` | `true` |
| `Show Tab 5` (boolean) | `true`, `false` | `false` |
| `Show Tab 6` (boolean) | `true`, `false` | `false` |
