# Chip

Neutral — обычная метка, круглая. Code — код или сигнатура, квадратная (Radius/sm).

- Разметка: [`chip.html`](chip.html) — все варианты по порядку, каждый с комментарием.
- Стили: [`chip.css`](chip.css) — требуют `foundations/tokens.css` и `code/base.css`.
- Корень: `<div>`, базовый класс `.oc-chip`
- Группа Forms, уровень atom, вариантов 2

## Свойства

| Свойство | Значения | По умолчанию |
|---|---|---|
| `Label` (text) | свободный текст | `"3/5"` |
| `Variant` (variant) | `Neutral`, `Code` | `"Neutral"` |

## Классы

Имена заморожены в [`../_names.json`](../_names.json): пути частей принадлежат дереву Figma, и
без карты вставленный соседний слой переименовал бы класс у части, которую никто не трогал.

| Класс | Слой Figma |
|---|---|
| `.oc-chip` | `Chip` |
| `.oc-chip__label` | `3/5` |
| `.oc-chip__3-5` | `3-5` |

## Непривязанные значения

1 шт. Значение уехало в CSS литералом и помечено маркером TODO. Это дыра в
библиотеке Figma, а не в коде: пока переменной нет, подставлять «похожую» нельзя.

| Свойство | Значение | Почему |
|---|---|---|
| `width` | `35px` | нет шкалы размеров: ширина задана числом |

## Где используется

- Neutral — обычная метка, круглая.
- Code — код или сигнатура, квадратная (Radius/sm).
- Входит в состав других компонентов (4 шт. по графу Figma).
