# ViewToggle

Переключатель вида: список или доска. Обойма 40 с гранью и радиусом md, внутри два SegmentOption. Отступ обоймы 2, не 3: при 3 сегмент вылезал на грань по пикселю сверху и снизу (1+2+34+2+1 = 40). Начертание подписи одно на оба состояния — разная жирность меняет ширину подписи, и обойма дёргалась бы при переключении.

- Разметка: [`view-toggle.html`](view-toggle.html) — все варианты по порядку, каждый с комментарием.
- Стили: [`view-toggle.css`](view-toggle.css) — требуют `foundations/tokens.css` и `code/base.css`.
- Корень: `<div>`, базовый класс `.oc-view-toggle`
- Группа Navigation, уровень organism, вариантов 2

библиотеке Figma, а не в коде: пока переменной нет, подставлять «похожую» нельзя.

| Свойство | Значение | Почему |
