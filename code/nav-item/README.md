# NavItem

Сгенерировано из набора компонентов Figma `NavItem`.

- Разметка: [`nav-item.html`](nav-item.html) — все варианты по порядку, каждый с комментарием.
- Стили: [`nav-item.css`](nav-item.css) — требуют `foundations/tokens.css` и `code/base.css`.
- Корень: `<div>`, базовый класс `.oc-nav-item`
- Группа Navigation, уровень molecule, вариантов 8

## Свойства

| Свойство | Значения | По умолчанию |
|---|---|---|
| `Label` (text) | свободный текст | `"Etapy"` |
| `Icon` (instance-swap) | свободный текст | `"56:2261"` |
| `State` (variant) | `Default`, `Hover`, `Pressed`, `Active` | `"Default"` |
| `Collapsed` (variant) | `False`, `True` | `"False"` |

## Состояния

Каждое значение `State` выходит дважды: статическим модификатором (`.oc-nav-item--state-hover`),
чтобы витрина показала все состояния разом, и псевдоклассом (`:hover`, `:active`, `:focus-visible`,
`:disabled`), чтобы компонент работал на живой странице. Наведение и нажатие гасятся на
выключенном элементе.

## Классы

Имена заморожены в [`../_names.json`](../_names.json): пути частей принадлежат дереву Figma, и
без карты вставленный соседний слой переименовал бы класс у части, которую никто не трогал.

| Класс | Слой Figma |
|---|---|
| `.oc-nav-item` | `NavItem` |
| `.oc-nav-item__icon-grid` | `Icons` |
| `.oc-nav-item__label` | `Etapy` |

## Непривязанные значения

3 шт. Значение уехало в CSS литералом и помечено маркером TODO. Это дыра в
библиотеке Figma, а не в коде: пока переменной нет, подставлять «похожую» нельзя.

| Свойство | Значение | Почему |
|---|---|---|
| `width` | `200px` | нет шкалы размеров: ширина задана числом |
| `icon-grid.iconStrokeWidth` | `1.5` | нет токена под толщину линии иконки |
| `width` | `60px` | нет шкалы размеров: ширина задана числом |
