# SegmentOption

Сегмент переключателя вида. Active — выбран ли; State — что с ним делает указатель: выбранный сегмент под курсором остаётся выбранным. Hover, Pressed и Focus в источнике не описаны, лестница взята у UnderlineTab, грань фокуса — у FormField. Disabled нет: в источнике его нет. У наведения на невыбранный сегмент нет своей подложки — в палитре нет ступени между Surface/Raised и Surface/Raised Hover, последняя занята выбранным.

- Разметка: [`segment-option.html`](segment-option.html) — все варианты по порядку, каждый с комментарием.
- Стили: [`segment-option.css`](segment-option.css) — требуют `foundations/tokens.css` и `code/base.css`.
- Корень: `<div>`, базовый класс `.oc-segment-option`
- Группа Navigation, уровень molecule, вариантов 8

## Свойства

| Свойство | Значения | По умолчанию |
|---|---|---|
| `Label` (text) | свободный текст | `"Lista"` |
| `Icon` (instance-swap) | свободный текст | `"56:2271"` |
| `Active` (variant) | `Idle`, `Active` | `"Idle"` |
| `State` (variant) | `Default`, `Hover`, `Pressed`, `Focus` | `"Default"` |

## Состояния

Каждое значение `State` выходит дважды: статическим модификатором (`.oc-segment-option--state-hover`),
чтобы витрина показала все состояния разом, и псевдоклассом (`:hover`, `:active`, `:focus-visible`,
`:disabled`), чтобы компонент работал на живой странице. Наведение и нажатие гасятся на
выключенном элементе.
