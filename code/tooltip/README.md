# Tooltip

Всплывающая подсказка. В библиотеке не было ни одной всплывашки как класса. Тень берётся стилем Elevation: своя тень не умеет обновляться вместе с системой.

- Разметка: [`tooltip.html`](tooltip.html) — все варианты по порядку, каждый с комментарием.
- Стили: [`tooltip.css`](tooltip.css) — требуют `foundations/tokens.css` и `code/base.css`.
- Корень: `<div>`, базовый класс `.oc-tooltip`
- Группа Feedback, уровень atom, вариантов 1

## Свойства

| Свойство | Значения | По умолчанию |
|---|---|---|
| `Text` (text) | свободный текст | `"Brakuje: polisa OC, dowód"` |

## Классы

Имена заморожены в [`../_names.json`](../_names.json): пути частей принадлежат дереву Figma, и
без карты вставленный соседний слой переименовал бы класс у части, которую никто не трогал.

| Класс | Слой Figma |
|---|---|
| `.oc-tooltip` | `Tooltip` |
| `.oc-tooltip__text` | `Text` |

## Непривязанные значения

2 шт. Значение уехало в CSS литералом и помечено маркером TODO. Это дыра в
библиотеке Figma, а не в коде: пока переменной нет, подставлять «похожую» нельзя.

| Свойство | Значение | Почему |
|---|---|---|
| `width` | `240px` | нет шкалы размеров: ширина задана числом |
| `borderWidth` | `1px` | нет токена под толщину обводки |
