# BoardColumnHeader

Сгенерировано из набора компонентов Figma `BoardColumnHeader`.

- Разметка: [`board-column-header.html`](board-column-header.html) — все варианты по порядку, каждый с комментарием.
- Стили: [`board-column-header.css`](board-column-header.css) — требуют `foundations/tokens.css` и `code/base.css`.
- Корень: `<div>`, базовый класс `.oc-board-column-header`
- Группа Stage, уровень organism, вариантов 1

## Свойства

| Свойство | Значения | По умолчанию |
|---|---|---|
| `Label` (text) | свободный текст | `"KUPIONA"` |

## Классы

Имена заморожены в [`../_names.json`](../_names.json): пути частей принадлежат дереву Figma, и
без карты вставленный соседний слой переименовал бы класс у части, которую никто не трогал.

| Класс | Слой Figma |
|---|---|
| `.oc-board-column-header` | `BoardColumnHeader` |
| `.oc-board-column-header__arrow-shape` | `ArrowShape` |
| `.oc-board-column-header__row` | `Row` |
| `.oc-board-column-header__label` | `KUPIONA` |
| `.oc-board-column-header__count-chip` | `CountChip` |
| `.oc-board-column-header__icon-car` | `Icons` |
| `.oc-board-column-header__count` | `3` |
