# CardDragOverlay

Сгенерировано из набора компонентов Figma `CardDragOverlay`.

- Разметка: [`card-drag-overlay.html`](card-drag-overlay.html) — все варианты по порядку, каждый с комментарием.
- Стили: [`card-drag-overlay.css`](card-drag-overlay.css) — требуют `foundations/tokens.css` и `code/base.css`.
- Корень: `<div>`, базовый класс `.oc-card-drag-overlay`
- Группа Overlays, уровень organism, вариантов 1
