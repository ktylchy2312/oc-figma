# Завендоренные подмножества Roboto

Это **вход** сборки, а не её выход. `build-foundations.mjs` читает эти файлы и вшивает их в
`foundations/fonts.css` как `data:font/woff2`. Каталог лежит внутри `foundations/` рядом с
выходами — не удаляйте его вместе с ними: генератор остановится с ошибкой и укажет на этот
файл, но восстановить сможет только человек.

## Зачем

Первая сборка взяла шрифт из уже вшитого листа прошлой версии — там было три подмножества:
`latin`, `cyrillic`, `cyrillic-ext`. Latin-ext среди них не было, **а продукт польский**.
Символы `ł ą ę ż ś ć ń ź` рисовались не Roboto, а тем, что нашлось в системе.

Ошибка не проявлялась на Windows: запасной шрифт случайно укладывался в допуск по ширине.
На Linux — не уложился, и CI поймал расхождение на `status-pill` (`Status=Błąd`, 70.22px
против 68px из Figma) на первом же прогоне. Затронут был 21 лист из 72.

`symbols` добавлено ради одного символа: `→` в описании `OfferTable`.

Проверка 9 в `verify.mjs` сторожит этот класс дефектов целиком: она собирает кодовые точки,
которые лист просит нарисовать, и требует, чтобы все они попадали в `unicode-range` вшитых
`@font-face`. Следующая недостающая локаль упадёт сразу и по делу, а не через полгода на
чужой машине.

## Происхождение

| | |
|---|---|
| семейство | Roboto, вариативный, `wght 100..900` |
| поставщик | Google Fonts |
| запрос | `https://fonts.googleapis.com/css2?family=Roboto:wght@100..900&display=block` |
| скачано | 2026-09-07 |
| лицензия | Apache License 2.0 |

| файл | байт | sha256 |
|---|---|---|
| `roboto-latin-ext.woff2` | 29392 | `cedb374b05a35034cf96db185db4eeb8f8ce49e1a56197673702ff11b5533d6e` |
| `roboto-symbols.woff2` | 20556 | `2addf2d86d7a5778653b36d551e97a39da52855f82fac7461cfc1bd86d460aed` |

Диапазоны `unicode-range` записаны в `tools/build-foundations.mjs`, в константе `VENDORED`,
дословно как их отдаёт Google Fonts. Меняете файл — меняйте и диапазон: подмножество и его
диапазон осмысленны только вместе.

## Как проверить

```
node -e "const fs=require('fs'),c=require('crypto');for(const f of ['latin-ext','symbols'])console.log(f,c.createHash('sha256').update(fs.readFileSync('foundations/fonts/roboto-'+f+'.woff2')).digest('hex'))"
```

## Как обновить

Скачать заново по тому же запросу, положить сюда, обновить байты и sha256 в таблице выше,
прогнать `npm run build && npm run verify`. Сеть нужна ровно в момент скачивания; сборка и
шлюзы работают офлайн и обязаны продолжать работать офлайн.
