Точка статуса 8×8. Живёт внутри пилюли статуса и в строках таблиц. Цвет означает состояние, поэтому статус никогда не передаётся только ей — рядом всегда есть текст.

Tone=Success
Tone=Warning
Tone=Error
Tone=Neutral

Токены: --radius-full, --status-error-text, --status-success-text, --status-warning-text, --text-tertiary

Без токена: width = 8px, height = 8px
